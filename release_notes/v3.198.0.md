# 版本更新说明 v3.198.0

| 版本号<br/>   | 更新日期<br/>   | 备注<br/>         |
| ------------- | --------------- | ----------------- |
| v3.198.0<br/> | 2026-03-09<br/> | 迭代版本更新<br/> |

## 新增功能

- EE-19846 系统新增对于多分支质量分析的支持。相关模块：技术债监控，项目表现-质量报表

## 功能优化

- EE-20143 支持以桶为粒度的对象存储连接信息配置
- EE-20112 分析引擎通过 line-diff 方式支持.sv 后缀的文件分析当量
- EE-20066 合并「团队摸底看板」和「团队摸底 2.0」，支持成员团队历史数据展示及开关控制。
- EE-20062 调整需求价值看板显示逻辑，增加定制化服务说明。
- EE-20057 合并「数据评估-自定义汇总」和「成员数据评估系统」，支持按人员、自定义字段枚举值及所属团队等多维度进行分组聚合。
- EE-20056 合并持续交付与 CICD 看板，支持项目多选并丰富指标数据。
- EE-20055 合并交付速率看板，支持关联与不关联需求提交的分类展示。

## OpenAPI DIFF

### 3.198.0

修改接口 `/repo/query` 查询已经添加的代码库， 本方法需要登录账户拥有至少以下一个 workspace 的权限: [system-config -> repositories，system-config -> analysis，toolbox -> large-screen]

```
 修改返回值

     修改字段 `repoAnalyticsSetting`

         新增字段 `incrementalRefRegex: string` 质量分析增量分支正则表达式
```

修改接口 `/repo/list-issues` 查询代码质量问题

```
 修改返回值

     新增字段 `aspectRef: string` 问题所属的代码库分支或标签名

     新增字段 `aspectRefCommit: string` 问题所属的代码库分支或标签的commit hash

     新增字段 `isBaseRef: boolean` 是否是基准分支或标签
```

修改接口 `/repo/set-analytics-setting` 配置分析设置（只更新传入的配置，不传入的配置项维持不变）， 本方法需要登录账户拥有至少以下一个 workspace 的权限: [tech-debts-monitoring -> codebase-maintainability，system-config -> analysis]

```
 修改请求参数

     新增字段 `incrementalRefRegex: string` 质量分析增量分支匹配正则表达式
```

修改接口 `/repo/get-functions` 查询代码库的函数列表

```
 修改返回值

     修改字段 `data` 函数列表

         新增字段 `aspectRef: string` 函数所属的代码库分支或标签名

         新增字段 `aspectRefCommit: string` 函数所属的代码库分支或标签的commit hash

         新增字段 `isBaseRef: boolean` 是否是基准分支或标签
```

修改接口 `/project/list-issues` 查询代码质量问题

```
 修改返回值

     修改字段 `data`

         新增字段 `aspectRef: string` 问题所属的代码库分支或标签名

         新增字段 `aspectRefCommit: string` 问题所属的代码库分支或标签的commit hash

         新增字段 `isBaseRef: boolean` 是否是基准分支或标签
```

修改接口 `/code-issue/list` 代码问题列表

```
 修改返回值

     修改字段 `data`

         新增字段 `aspect_ref: string` 问题所属的代码库分支或标签名

         新增字段 `aspect_ref_commit: string` 问题所属的代码库分支或标签的commit hash

         新增字段 `is_base_ref: boolean` 是否是基准分支或标签
```
