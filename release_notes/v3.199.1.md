# 版本更新说明 v3.199.1

## 新增功能

- EE-20181 OpenAPI 新增 /repo/commit/rev-list 接口，支持按 ref 查询 commit 列表
- EE-20172 支持数据源 scope 暂停自动同步功能，允许在自动同步任务中跳过特定 scope，同时保留手动同步能力
- EE-20145 tapd 数据源 - 增加"同步起始时间"配置项
- EE-20133 License 增加精简版支持
- EE-20069 新增团队成员项目贡献画像看板，支持跨看板跳转及参数传递

## 功能优化

- EE-20158 优化个别 commit 因源代码文件语法错误，导致语法树解析错误，当量异常情况
- EE-20060 合并「质量保障」与「质量过程改进」看板，并优化看板布局与指标融合

## OpenAPI DIFF

新增接口 `/repo/commit/rev-list` 通过 git rev-list 筛选 commit，返回 commit 列表（包含基本信息和指标数据）。返回的 commit 列表默认按时间倒序排列（最新的 commit 在前）。建议使用 since 和 until 参数限定每次查询的 commit 数量，分批查询以获得更好的性能和稳定性。

## 指标数据的变化

- AE 默认开启 AST 解析失败 fallback 到 linediff 计算当量
- AE 增加当量异常（tree-diff eloc 10 倍于增删行）会取增删行的 10 倍为上限
