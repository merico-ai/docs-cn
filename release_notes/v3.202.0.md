# 版本更新说明 v3.202.0

| 版本号<br/>   | 更新日期<br/>   | 备注<br/>         |
| ------------- | --------------- | ----------------- |
| v3.202.0<br/> | 2026-05-06<br/> | 迭代版本更新<br/> |

## 功能优化

- EE-20287 贡献者排行页面支持按项目组筛选。
- EE-20262 openapi/v2/app/data_source/csv_issue/import：增加 taskId 参数校验，如果存在，必须为 uuid
- EE-20270 支持通过 OpenAPI 导入 CSV 测试用例数据。

## 修复

- EE-20265  修复数据导出 CSV 记录数异常固定为 5 万条的问题。

## OpenAPI DIFF

- 新增接口 `/v2/app/data_source/csv_qa/import` 校验 CSV 格式、上传至 MinIO 并触发异步导入任务， 本方法需要登录账户拥有至少以下一个 workspace 的权限: [system-config -> data-source-config]
- 修改接口 `/project/sprint/import-csv` 创建导入 csv issue 的异步任务，需保证所有的 board 在 web 界面中已上传过一次，与项目已有关联， 本方法需要登录账户拥有至少以下一个 workspace 的权限: [system-config -> data-source-config]
  修改请求参数
  修改字段 `taskId` 任务 id,如果指定且 incremental 为 false, 则会覆盖该任务对应的看板的 issue_repo_commits 数据
  类型从 `string` 改为 `string(uuid)`
