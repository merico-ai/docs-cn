# 版本更新说明 v3.204.0

| 版本号<br/>   | 更新日期<br/>   | 备注<br/>         |
| ------------- | --------------- | ----------------- |

## 新增功能

- EE-20303 支持全局配置测试函数当量权重，允许通过权重系数调整测试文件的当量计算。

## 修复

- EE-20384 优化 OpenAPI Commit 查询接口过滤逻辑并修正文档注释。
- EE-20393 增加对数据源同步频率 cron 表达式的校验

## OpenAPI DIFF

新增接口 `/test-file-config/get-weight` 获取测试文件当量权重， 本方法需要登录账户拥有至少以下一个 workspace 的权限: [system-config -> analysis-settings]

新增接口 `/test-file-config/update-weight` 修改测试文件当量权重， 本方法需要登录账户拥有至少以下一个 workspace 的权限: [system-config -> analysis-settings]

修改接口 `/repo/commit/list-by-commit-label` 如果一个 commit 有 2 个 label_value，返回结果里会有两条 commit 记录，label_value 不同。

```
 修改请求参数

     新增字段 `authorStartTime: string(date-time)` Author起始时间，例如：2022-04-01T07:35:54.413Z

     新增字段 `authorEndTime: string(date-time)` Author截止时间，例如：2022-04-01T07:35:54.413Z

 修改返回值

     修改字段 `data` 列表

         新增字段 `authorTime: string` 提交作者时间，格式为 ISO，如 2017-10-09T07:26:45.000Z

         新增字段 `commitTime: string` 提交时间，格式为 ISO，如 2017-10-09T07:26:45.000Z
```

修改接口 `/project/commit/list` 查询项目 commit 列表

```
 修改请求参数

     删除字段 `pagesize: integer` 废弃，请使用pageSize代替
```
